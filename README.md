**Huge Problem(Pain Point):** 디지털 서비스의 장벽은 비당사자가 고령자·외국인의 인지적 부담을 체감하기 어렵다는 데서 반복된다.

**솔루션 한 줄 정의:** 역할 기반 불편 과제를 직접 수행하고 소요 시간과 AI 리포트로 장벽을 성찰하게 한다.

**현재 상태:** 공모전 프로토타입

**문제 해결 중심의 사고 흐름**

1. **관찰** — 접근성 통계만 읽는 것으로는 작은 글씨·복잡한 표현·낯선 절차가 주는 부담을 자기 경험으로 연결하기 어려웠다.
2. **선택** — 사용자에게 제약이 있는 역할을 부여하고 과제 수행 시간과 선택 결과를 성찰 자료로 사용했다.
3. **구현** — Streamlit 다단계 시뮬레이션, 역할별 폼, 디지털 격차 차트와 개인화 AI 리포트를 구현했다.
4. **검증과 한계** — 배포된 프로토타입으로 전체 체험 흐름을 제시했다. 역할 시뮬레이션이 실제 당사자 경험을 완전히 대변하지 않는다는 한계가 있다.
